# 5. Limites et risques

Les risques a documenter sont les permissions privilegiees, les oracles, les arrondis, la liquidite, le MEV, les appels externes et les changements de version. Une interface utile montre les bornes effectives et signale les etats d urgence, de pause ou de liquidation. Les licences et les dependances du depot font partie du perimetre de reutilisation. Le depot source expose notamment Credit Accounts, Credit Manager, adapters, quotas, diesel tokens, liquidation.
