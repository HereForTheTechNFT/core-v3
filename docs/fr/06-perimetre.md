# 6. Perimetre documentaire

Ce parcours couvre l architecture et les mecanismes visibles dans le depot source, sans constituer un conseil financier ni une garantie de securite. Il ne remplace ni un audit, ni une lecture des commits recents, ni une verification des adresses deployees. Les contrats peuvent evoluer et les parametres de risque doivent etre revalides avant toute integration. Aucune nouvelle installation, compilation, execution de test ou deploiement n a ete realisee pour ce parcours documentaire. Pour aller plus loin, consulter la suite de tests et les audits references par le depot.
